## 📌 Overview
**GravityLeosMAD** is an Android mobile application developed as part of a Mobile Application Development project. The application demonstrates core Android development concepts including UI design, activity management, and integration of application logic using a structured and scalable approach.

---

## 🎯 Purpose
The purpose of this project is to design and develop a functional mobile application that showcases:

- Android application development fundamentals  
- User interface design and interaction  
- Modular and maintainable mobile architecture  
- Practical implementation of mobile app workflows  

---

## 🏗️ Architecture

The application follows a **standard Android architecture**:

- **UI Layer** → Activities, layouts, and user interactions  
- **Logic Layer** → Handles business logic and processing  
- **Data Layer** → Manages data flow within the app
